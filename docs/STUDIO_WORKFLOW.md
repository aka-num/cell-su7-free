# Cell SU7 Studio v3.5：三步操作 + 可视化画布

这个版本改的是**桌面操作流程**，不是图像矢量化算法。打开软件后只需在一个窗口内工作，不需要在三个标签页之间来回切换。

## 0. 安装与启动

```powershell
python -m pip install -r requirements.txt
# 如果要使用 DeepSeek / 其他视觉模型：
python -m pip install -r requirements-ai.txt
# 如果要使用免费的 Tesseract OCR：
python -m pip install -r requirements-optional.txt
python app.py
```

使用本地 OCR 还须在电脑上安装 Tesseract 的可执行程序。Windows 系统通常已自带 Tkinter；Linux 需要系统包 `python3-tk`。所有旧版 CLI 参数仍可用。

## 1. 导入图片

点击 **选择图片** 选取 PNG、JPG、WebP、BMP、TIFF 或 SVG。第一步会预览原图，自动给出默认输出名称。

接着选择：

- **不识别文字**：适合 SVG 或只需提取轮廓的图片；直接去第三步，不会连外网。
- **本地 OCR**：使用安装好的 Tesseract，免费，不传图片，进入第二步校对。
- **DeepSeek OCR**：使用你自己的 DeepSeek 官方密钥发送图片，需确认请求次数与可能费用，进入第二步校对。默认单图一次；`2x2` 会调用四次。
- **其他视觉 OCR / AI 语义图形重建**：展开“其他 AI 模式（实验功能）”后才能看到。前者进入校对；后者更适合简单流程图，直接在导出步骤调用视觉模型，依然必须单独确认费用。语义模式不是高保真无损重建。

## 2. 校对文字

点击 **开始识别文字**。识别完成后，左侧显示红框与序号，右侧表格显示每段文字及坐标。

- 双击表格行或选中后点“修改选中”，可直接编辑文字、`左 X` / `上 Y` / `右 X` / `下 Y` 和字号。
- 点击图片里的某个文本框，右边表格会选中对应项。
- 可以添加或删除文字；每次修改都会将审核状态重置为“尚待确认”。
- **保存 JSON** 能保存中间结果，之后用 **导入已有 JSON** 恢复编辑，不需要再次调用云端 OCR。重新导入时会校验清单是否对应同一张图片的画布尺寸。
- 或点击 **画布拖动文字 / 图形**，直接在左右对照的真实矢量画布中拖动，文字框移动会同步回审核清单。
- 检查完毕点 **确认校对完成 → 导出**，系统保存审核清单并转到第三步。
- 也可以点 **跳过文字 → 导出**：未审核的识别结果不会悄悄恢复到 PPTX 中。

> 识别内容与坐标来自模型建议，不等于已经确认无误。局部去字可能损伤与文字交叠的箭头、蛋白质或曲线，因此默认关闭。

截图示例：`previews/02-review-demo-mock.png`。其中 8 条文字是**已有的模拟 OCR 演示数据**，不是本次连接 DeepSeek 产生的实时识别。

## 3. 导出

默认生成原生可编辑 PPTX，并可同时生成 SVG、可选 PDF 和质量对照 HTML。

- **常规导出始终在本地完成**，不会重复发送原图或产生 OCR 调用费用。
- 只有已审核文字才能用于重建的可编辑文本；局部去字开关在审核前不可用。
- 高级描摹参数默认隐藏。要修改 VTracer / contour 和颜色数，展开“显示高级矢量化选项”。
- 高级 AI 语义重建是例外：导出时会显示上传目的地、模型与费用确认，不应混淆成离线模式。

## AI Key 设置与网络诊断

点击右上角 **AI 接口设置**。从下拉框选择“DeepSeek 官方”时会自动填入官方地址及视觉模型。API Key 默认仅在当前程序内存保存；普通“保存配置”只存非敏感的 URL/模型名。要长期保存，可显式点击“存入系统凭据库”（需要安装 keyring）。切换服务商时会清空当前粘贴的 Key，避免意外发送到其他服务端。

“测试连接（免费）”和“诊断 DeepSeek 网络（免费）”都不会上传图片。网络专用诊断也可在终端运行：

```powershell
python tools/diagnose_deepseek.py
python tools/diagnose_deepseek.py --check-key
```

**不要在聊天、截图或 Git 仓库中公开密钥。** 曾经公开的密钥应在服务商控制台撤销重建；删除聊天消息不能使其失效。

## 当前已知局限

- 仅优化 UI 体验；科研机制图的细节恢复、复杂遮挡、背景渐变、文字与底图重复仍可能不理想。
- 不支持在软件中直接生成 Illustrator 原生 AI 文件；可用 SVG 在 Illustrator 或 Inkscape 中进一步编辑。
- v3.5 已支持在独立画布拖动文字框与图形位置，但尚不支持曲线锚点级编辑和图层重排。见 [画布操作](VISUAL_CANVAS.md)。
- 云端 API 精度与费用由服务商决定；自动化测试使用模拟返回数据，未据此声称超越原项目。

## v3.4：窗口缩小后页面如何滚动

无需缩放整个桌面，也无需放大窗口。使用各页面右边的滚动条、鼠标滚轮或触控板可查看页面下面的选项；如果控件在高 DPI 下过宽，底部会出现横向滚动条。还支持 Shift+滚轮横移，Ctrl+Home/End 跳转顶部/底部。

校对页在狭窄窗口会改为上下排列：原图在上，文字表格与确认按钮在下。AI 设置和文字编辑弹窗也有独立滚动条。如果滚轮在 OCR 文字表格内部，先滚动表格，达到表格边界后继续滚动整个页面。

开发者回归测试：
```bash
python -m pytest -q

```
